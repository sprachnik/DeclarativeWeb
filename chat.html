DeclarativeWeb Chat Info

API Setup

Add ANTHROPIC_API_KEY as an environment variable in your Netlify dashboard (Site settings → Environment variables).

How It Works

  1. Initial request: LLM generates full array of blocks with _seq ordering
  2. Updates: LLM uses patch protocol - returns ONLY changed blocks
  3. Patching: Blocks matched by _uid, merged into existing content
  4. Rendering: Changed blocks highlighted and scrolled into view

Patch Protocol

  • _uid: existing ID = update, "NEW" = insert
  • _seq: position in final array (0, 1, 2...)
  • _delete: true: remove the block
